# Приём заявок через Google Apps Script

Форма отправляет заявку на адрес скрипта в Google, а скрипт:

1. добавляет строку в Google Таблицу (дата, имя, ник, встречи, ссылка на чек) и кладёт чек в папку на Google Диске;
2. присылает в Telegram сообщение с именем, ником, встречами и файлом чека.

Таблица — главное хранилище. Если Telegram вдруг не ответит, заявка всё равно сохранится, а ошибка будет видна в **Executions** скрипта. Токен бота хранится в настройках скрипта — на сайте его нет.

Займёт минут 15. Делать лучше с аккаунта Google, в котором потом будет таблица с заявками.

## 1. Бот

1. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя и username (должен заканчиваться на `bot`).
2. BotFather пришлёт **токен** вида `123456789:AAH...`. Никому его не пересылайте и не вставляйте в код сайта.

## 2. Чат для заявок

- **Лизе в личку:** Лиза открывает бота и нажимает «Start».
- **В группу организаторов:** добавьте бота в группу и напишите там `/start@имя_бота`.

## 3. Скрипт

1. Откройте [script.google.com](https://script.google.com) → **New project**. Назовите проект, например, «бонмо — заявки».
2. Удалите всё в файле `Code.gs` и вставьте содержимое [`code.gs`](code.gs) из этой папки. Сохраните (Ctrl+S).
3. Слева ⚙️ **Project Settings** → внизу **Script properties** → **Add script property**:
   - `TELEGRAM_BOT_TOKEN` — токен из шага 1.
   - Сохраните.

## 4. Узнать id чата

1. Вернитесь в редактор (слева `<>` **Editor**).
2. В списке функций над кодом выберите **showChatIds** → **Run**.
3. Google попросит доступ: **Review permissions** → выберите аккаунт → «Google hasn't verified this app» → **Advanced** → **Go to … (unsafe)** → **Allow**. Это нормально для собственного скрипта: он просит только отправлять запросы в интернет (к Telegram).
4. Внизу в **Execution log** появятся строки вида `123456789 — Лиза` или `-1001234567890 — Организаторы бонмо`. Число слева — id чата (у групп он с минусом).
5. Добавьте в **Script properties** ещё одно свойство: `TELEGRAM_CHAT_ID` — это число.
6. Выберите функцию **sendTestMessage** → **Run**. В чат должно прийти «Проверка: бот формы бонмо́ подключён ♥».

## 5. Таблица и папка для чеков

По умолчанию скрипт сам создаст на вашем Google Диске таблицу «бонмо — заявки» и папку «бонмо — чеки».

**Хотите свои таблицу или папку** — до запуска добавьте их id в **Script properties**:

- `SPREADSHEET_ID` — из ссылки на таблицу: `docs.google.com/spreadsheets/d/`**`<id>`**`/edit`
- `RECEIPTS_FOLDER_ID` — из ссылки на папку: `drive.google.com/drive/folders/`**`<id>`**

Можно указать только одно из двух — второе создастся само. В своей таблице скрипт добавит лист «Заявки» с заголовками.

Затем в редакторе выберите функцию **setupSpreadsheet** → **Run**. Google попросит новые разрешения — к таблицам и Диску (как в шаге 4). В журнале появятся ссылки на таблицу и папку, а в Script properties — `SPREADSHEET_ID` и `RECEIPTS_FOLDER_ID`.

Чеки и таблица видны только владельцу аккаунта. Чтобы заявки видели другие организаторы — откройте им доступ к таблице и папке через «Настройки доступа».

## 6. Опубликовать

1. Справа сверху **Deploy** → **New deployment**.
2. ⚙️ рядом с «Select type» → **Web app**.
3. **Execute as:** Me. **Who has access:** Anyone.
4. **Deploy** → скопируйте **Web app URL** (заканчивается на `/exec`).

Этот адрес не секретный — он всё равно будет виден в коде страницы.

## 7. Подключить к сайту

- **Локально:** создайте в корне проекта файл `.env.local` со строкой
  `NEXT_PUBLIC_SUBMIT_ENDPOINT=https://script.google.com/macros/s/…/exec` и перезапустите `yarn dev`.
- **На GitHub Pages:** в репозитории **Settings → Secrets and variables → Actions → Variables → New repository variable**: имя `SUBMIT_ENDPOINT`, значение — тот же адрес. Сайт подхватит его при следующем деплое.

## Если поменяли код скрипта

**Deploy → Manage deployments → ✎ (Edit) → Version: New version → Deploy.** Адрес останется прежним. Без этого шага сайт продолжит работать со старой версией.

В русском интерфейсе: **«Начать развертывание» → «Управление развертываниями» → ✎ → Версия: «Новая версия» → «Начать развертывание»**.

## Если что-то не приходит

В редакторе скрипта слева **Executions** — там видны все вызовы и текст ошибок.
