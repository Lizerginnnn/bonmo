# bonmo-form

Форма регистрации на встречи клуба бонмо́: имя, ник в телеграм, выбор встреч, блок оплаты и загрузка чека, с живой валидацией. Чистый HTML, CSS и JS, без сборки и зависимостей.

## Структура

```
index.html     разметка формы
css/style.css  стили страницы: фон, карточка, шапка, блок оплаты, экран «отправлено»
js/main.js     правила валидации и отправка в Google Apps Script
ui/            компоненты, у каждого своя папка с .js и .css
  tokens.css   цвета, шрифты и размеры (CSS-переменные)
  index.js     подключает все компоненты
  index.css    подключает токены и стили всех компонентов
  error/          <ui-error> — выезжающее сообщение об ошибке
  button/         <ui-button> — со спиннером (свойство loading)
  input/          <ui-input>
  checkbox/       <ui-checkbox> — карточка с галочкой
  checkbox-group/ <ui-checkbox-group> — fieldset с заголовком и общей ошибкой
  uploader/       <ui-uploader> — кнопка загрузки и имя выбранного файла
```

## Запуск

JS подключается как ES-модули, а они не работают при открытии файла напрямую (`file://`). Нужен локальный сервер:

```sh
python3 -m http.server 8000
# http://localhost:8000
```

## Компоненты

Компоненты сделаны как custom elements без Shadow DOM: внутри рендерятся обычные `<input>` и `<button>`, поэтому форма и `FormData` видят их как обычные поля.

У полей (`ui-input`, `ui-checkbox-group`, `ui-uploader`) есть свойство `error`: строка с текстом показывает ошибку и красит рамку, пустая строка прячет. Когда показывать ошибки, решает `js/main.js`.

Адрес Google Apps Script задаётся в `ENDPOINT` в `js/main.js`.

Чтобы добавить компонент, создайте папку `ui/<имя>/` с файлами `<имя>.js` и `<имя>.css` и добавьте их в `ui/index.js` и `ui/index.css`.
