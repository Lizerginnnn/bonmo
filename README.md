# bonmo

Форма регистрации на встречи клуба бонмо́.

Сайт: **https://lizerginnnn.github.io/bonmo/**

## Запуск

Нужны Node.js 22 и Yarn (включается командой `corepack enable`).

```sh
yarn install
yarn dev
```

Откроется на http://localhost:3000. С телефона в той же Wi‑Fi сети — `http://<IP компьютера>:3000`.

Другие команды:

```sh
yarn build      # собрать сайт в папку out/
yarn preview    # посмотреть собранный сайт
yarn typecheck  # проверить типы
```

## Публикация

Сайт публикуется сам при каждом пуше в `main` (GitHub Actions → GitHub Pages).

Настроено один раз в репозитории:

- **Settings → Pages → Source:** GitHub Actions
- **Settings → Secrets and variables → Actions → Variables:** `SUBMIT_ENDPOINT` — адрес Apps Script

## Встречи — LIZA.json

Список встреч на форме — в файле [`LIZA.json`](LIZA.json) в корне:

```json
{
  "meetings": [
    "20 сентября — Шарлотта Бронте «Джейн Эйр»",
    "4 октября — лекция «Реальная роль богов в жизни древних греков на примере \"Одиссеи\"»"
  ]
}
```

- Каждая встреча — строка в двойных кавычках `"…"`, встречи разделяются запятой. После последней запятой не нужно.
- Внутри текста лучше использовать «ёлочки». Если нужны прямые кавычки — перед каждой ставится `\`: `\"Одиссеи\"`.
- Текст встречи уходит в заявку, в таблицу и в Telegram как есть.

Поменять можно прямо на сайте GitHub: открыть `LIZA.json` → карандаш ✎ → исправить → **Commit changes**. Через пару минут сайт обновится сам.

Если в файле ошибка (забыта запятая или кавычка), сайт не обновится, а на сайте останется прежняя версия. Во вкладке **Actions** будет красный крестик с указанием строки в `LIZA.json`.

## Что где менять

- Встречи — `LIZA.json`
- Цены, реквизиты, контакты — `src/config/registration.ts`
- Тексты страницы — `src/components/`
- Цвета и шрифты — `src/design-system/tokens.css`
